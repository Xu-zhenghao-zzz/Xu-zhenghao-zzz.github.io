Automated Video-to-QA Pipeline

Planned release

An automated pipeline for constructing video understanding datasets. The system builds retrieval-augmented context from video-related knowledge, processes video frames and audio, and uses LLM agents to generate candidate question-answer pairs followed by human verification.

Scale: 600+ videos, 10,000+ QA pairs, 10+ controlled experiments.

Focus: scalable multimodal dataset construction, LLM-agent workflows, and data quality control.

Stack: Python, vLLM, RAG, Qwen, DeepSeek, LLM agents, multimodal processing.

Repository URL will be added after release.

Graph-based RL Evaluation Suite

Research code

An experimental suite for evaluating the generalization and robustness of graph-structured reinforcement learning policies. The suite originated from my experimental work on GNN + PPO structured decision-making systems.

It includes cross-topology generalization, unseen-environment evaluation, parameter sensitivity analysis, workload stress testing, and automated experiment aggregation and analysis.

Stack: Python, PyTorch, PPO, GNN, NetworkX.

Public code link will be added only with collaborator approval.

Joint Decision-Making Simulation Toolkit

In preparation

A Python simulation toolkit for studying complex joint decision-making problems. I have been responsible for problem formulation, core implementation, experimental design, and analysis.

The current application involves computation and routing decisions in UAV environments, while my main interest in the project is in RL environment design, multi-variable decision modeling, and reproducible experimental systems.

Stack: Python, simulation, NumPy/Pandas, NetworkX.
